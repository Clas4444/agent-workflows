# Loop Research Repo

Define the repository decision and criteria. Search official repository pages,
documentation, releases, issues, and license sources first. Record URL,
version/date, evidence, confidence, and fact versus inference. Compare
alternatives in a table and never clone private sources, authenticate, install,
or send sensitive data without authorization. Mark each check `PASS`, `FAIL`,
`BLOCKED`, or `NOT_RUN`. Checkpoint every distinct search angle. If no new
angle remains or materially identical results occur more than three times,
write the consolidated report and stop; never sleep to consume duration.
