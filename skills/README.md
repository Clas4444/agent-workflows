# Standalone skills

| Skill | Invoke | Package |
|---|---|---|
| Workflow Setup | `$workflow-setup` | [workflow-setup](workflow-setup/SKILL.md) |

Copy a complete skill folder into the selected host's skill directory. Each
package includes its own instructions, UI metadata and required resources.
No repository imports are needed after copying. For project installation,
`workflow-setup` can live under `.agents/skills/workflow-setup`.

The 53 bounded workflows remain canonical under `.github/skills/`, with declared
copies under `.agents/skills/` and `.claude/skills/`. They use the existing bundle
installer. Standalone packages here are separate and are not silently included
by `install_skills.py --all` or added to the 53-workflow manifest.

Workflow Setup designs steps, bindings and result routes. It does not require
Agent Attention and does not execute a task merely by creating a design. The
helper, reference, example and lookup catalog are generated by
`python scripts/workflow_assets.py --write`; edit the helper source in `scripts/`
and its reference generator before regenerating bundled copies.

See the [setup guide](../docs/guides/workflow-setup.md) and
[repository layout](../docs/reference/repository-layout.md). Installation byte
checks and isolated helper execution do not establish native picker discovery.
